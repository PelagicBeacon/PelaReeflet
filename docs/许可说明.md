# 许可证、商标与署名

PelaReeflet 的代码用 **MIT**。这条线画得很清楚：

- **代码**：随便用、随便改、随便嵌入、商用、闭源分发都可以，保留版权声明即可。
- **品牌**：名称与 Logo 不随 MIT 授权，别拿它冒充官方。

## 为什么是 MIT + 商标，而不是「禁止修改外观」的自定义协议

组件是要被嵌进别人网站里的东西。任何限制外观的条款都会让集成方先掂量法律风险，
最后的结果往往是「不用了」。MIT 让接入成本降到零，品牌保护交给商标政策——
这也是 Kubernetes、Rust、Next.js 这些项目的做法。

代价要讲明白：**MIT 允许别人去掉水印**。法律上你拦不住。能拦住的是「去掉水印还叫
PELAGIC BEACON」——那属于商标侵权，有 [TRADEMARK.md](../TRADEMARK.md) 兜着。

## 关于署名：一个请求，不是一个条件

组件默认会在右侧显示 **PELAGIC BEACON**，正下方紧跟着「开源协议 · 关于我们」两个链接，
都收在组件框内，「关于我们」指向我们的 GitHub 组织主页。

**我们希望你保留它。** 一个角标不会影响谁的页面美观，却是这个项目被更多人看见的
唯一途径——如果 PelaReeflet 帮到了你，最好的回报就是留着它。

这件事**不是 MIT 的附加条件**：

- 保留 → 不需要任何额外操作，开箱即用。
- 想去掉 → 把 `REEFLET_ATTRIBUTION=false` 或改前端代码都行，**但请同时换掉名称与
  Logo**，别让用户误以为是官方版本。

## 如果你改了品牌对外发布

1. 改 `REEFLET_BRAND`、`REEFLET_LOGO`，或直接改 `static/widget/pelareeflet.js` 里的默认值；
2. 换掉 `static/brand/` 下的图标；
3. 不要使用 PELAGIC BEACON / 远洋辉光 / PelaReeflet 等名称与近似标识。

这样既符合 MIT，也不触碰商标。
