1. 引入组件

一行 script + 一个容器，组件会自动挂载。

index.html
<script src="{{ request.url_root }}embed/pelareeflet.js" async defer></script>

<div class="pelareeflet" data-callback="onReefletToken"></div>

<script>
  function onReefletToken(ticket) {
    document.querySelector('[name="reeflet"]').value = ticket;
  }
</script>

2. 主题

三种取值，属性优先于服务端默认配置，同一页面可混用。

<!-- 深色（默认） -->
<div class="pelareeflet"></div>

<!-- 浅色 -->
<div class="pelareeflet" data-theme="light"></div>

<!-- 跟随系统，实时响应切换 -->
<div class="pelareeflet" data-theme="auto"></div>

3. 后端核验

前端拿到的只是 ticket，真正的结论由你的服务端向 PelaReeflet 换取。

server.py
import requests

def verify(ticket, user_ip=None):
    r = requests.post("{{ request.url_root }}api/v1/siteverify", json={
        "secret": REEFLET_SECRET,      # 与部署端的 REEFLET_SECRET 一致
        "response": ticket,
        "remoteip": user_ip,           # 可选：传了就校验 IP 绑定
    }, timeout=3)
    return r.json().get("success") is True

# { "success": true, "challenge_ts": 1767225600, "hostname": "example.com" }
# { "success": false, "error-codes": ["replayed"] }

4. 接口一览

方法路径说明
POST/api/v1/challenge签发挑战，单 IP 每秒限 2 次
POST/api/v1/check交互关卡：轨迹、按压时长、自动化特征
POST/api/v1/solve提交 PoW 答案，换取 ticket
POST/api/v1/siteverify服务端验票（本页用的就是它）
GET/embed/pelareeflet.js可嵌入组件

5. 错误码

reason含义
replayed票据已用过（一次性）
expired票据过期
bad_ip换网络了，需重新验证
wrongPoW 答案不对
need_gate跳过了点击关卡
automation无头 / 自动化环境
